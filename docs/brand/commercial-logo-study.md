# Repolane：商业品牌标志研究

2026-09-07。Repolane 已由用户选定；所有已展示的 Logo 候选均未获认可。本文记录设计方和品牌方的案例，以及对下一轮草图的约束，不是新 Logo 的定稿。

## 案例与启发

| 案例 | 来源中的事实 | 对 Repolane 的启发（设计判断） |
| --- | --- | --- |
| Slack / Pentagram | 保留原有井号的识别基础，用两类基本形状重构，并解决不同尺寸与背景下的复现问题 | 先建立统一的构形规则，局部线宽、圆角和间距必须协调；不要随意拼图 |
| Asana / Moving Brands | 保留三个圆点，改变为围拢关系来表达合作；官方规范同时约束图形、字标和留白 | 独特性可以来自排列和比例，无需增加复杂切口；符号与字标应共同设计 |
| Dropbox / COLLINS | 通过相同菱形组成统一标志，并将产品价值从文件同步扩展到团队协作 | 图形要能支撑产品整体定位，不能只像某一项功能的按钮 |
| FedEx / Lindon Leader | 设计师重新处理字形以形成负空间箭头，并强调看不到箭头也不应削弱标志的表达 | 寓意应是附加价值；不依靠讲解，也要有完整、好认的外观 |

## 前几轮的问题

- 在 H、帆、容器、合流、折页之间反复更换对象，却没有持续打磨一个形状的比例。
- 将“图形有寓意”当成“图形好看”的证据。用户已经明确否定，不能继续把任何旧稿标为推荐方向。
- 大图符号与标题栏里的符号有生成差异，小图仅为示意，不能当作像素级验证。
- 切割圆形、斜条纹等轮廓容易落入现有科技品牌的常见形式；更多斜切并不自动增加设计质量。
- 字标多数只是普通无衬线文字，与符号缺少经过验证的比例关系。

## 下一轮设计约束

定位继续是 GitHub 桌面工作区；保留冷蓝灰产品配色，不引入参考品牌的配色和独特图形。

以一个紧凑的独立符号为目标。可以使用两三个基本形状，但形状间要有明确的比例、间隔和重心关系。只选一个主要识别特征，避免同时塞入道路、仓库、字母和箭头。

先画轮廓变体，不再一口气跳到完整品牌展示板。每个方向同时比较胖瘦、间距与转折，筛选后配合字标。黑白、单色以及浅深背景都要看；色彩可以贡献性格，但不能遮盖轮廓问题。

选中概念后，用可编辑矢量重建，检查 16、20、24、32 px 的实际渲染，并检查 1200 px 标题栏与 Dock 图标的视觉重量。生成图中的小图不能替代这些验证。

在推荐之前，先检查是否像已有品牌、功能图标、交通标识或电竞徽标。每个候选给出缺点，不用“高级、独特”等形容词代替评估。
